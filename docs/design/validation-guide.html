Guide de revue visuelle

Substitut aux captures d'écran de la phase 5. Chaque encadré est une iframe qui charge la vraie page servie par uvicorn, dans un état forcé par l'URL : ?demo=…&theme=…. Aucune maquette n'est redessinée ici : ce que vous voyez est le produit.

Pourquoi un guide et pas des images ?

Playwright ne peut pas être installé dans cet environnement (npx playwright install chromium échoue au téléchargement, deux tentatives, aucun navigateur système). Les captures avant/après en PNG sont donc impossibles, et je ne les fabrique pas. Ce fichier est le substitut annoncé en phase 0 : il rend les états réels, dans les deux apparences et les deux largeurs, et laisse la capture à votre navigateur (Ctrl+Maj+P → « Capture d'écran pleine page »).

Serveur requis : uvicorn app:app --host 0.0.0.0 --port 8000, puis ouvrir docs/design/validation-guide.html depuis le disque. Les iframes pointent vers http://localhost:8000.

6 · Navigation clavier et préférences

À faire dans la vraie page (http://localhost:8000/), pas dans les iframes :

  • Tab depuis le chargement : lien d'évitement → historique → nouvelle conversation → 4 cartes → zone de saisie → envoyer → arrêter.
  • Anneau de focus visible sur chaque arrêt ; la capsule entière s'illumine quand le champ est actif.
  • Entrée envoie, Maj+Entrée ajoute une ligne, Échap ferme la feuille et rend le focus au déclencheur.
  • Le compteur n'apparaît qu'à partir de 3 500 caractères.
  • Réglages système : « Réduire les animations » (plus de déplacement, plus de pulsation), « Réduire la transparence » (surfaces opaques), « Augmenter le contraste » (contour réel).

Sans backdrop-filter, le repli @supports remplace le verre par une surface opaque : à vérifier dans Firefox avec layout.css.backdrop-filter.enabled=false.
